# Checkmate-daily-tracker
CheckMate Daily Tracker helps you turn plans into progress with a clean task list, tick-off goals, reminders, notes, and weekly/monthly planning views — because every completed task is a checkmate.

## Features
- To-do list with tick-off option
- Date and time-based planning
- Reminders
- Notes section
- Weekly and monthly view
- Minimal and distraction-free interface

## Tech Stack
- HTML
- CSS
- JavaScript
